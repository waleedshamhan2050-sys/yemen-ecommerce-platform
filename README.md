# منصة التجارة الإلكترونية اليمنية 🇾🇪
# Yemen E-Commerce Platform

منصة تجارة إلكترونية متكاملة وآمنة مصممة خصيصاً لسوق اليمن، توفر تجربة تسوق سلسة وآمنة للعملاء مع أدوات قوية لإدارة المتاجر والمنتجات.

## نظرة عامة على المشروع

هذا المشروع هو منصة تجارة إلكترونية شاملة تجمع بين:
- **واجهة مستخدم حديثة وسهلة الاستخدام** للعملاء
- **لوحة تحكم متقدمة** للتجار والبائعين
- **نظام إدارة متكامل** للمسؤولين
- **نظام دفع آمن** يدعم وسائل الدفع المحلية اليمنية
- **نظام إشعارات فورية** للعملاء والتجار

## الميزات الرئيسية

### 🛍️ ميزات العملاء
- **التسجيل والمصادقة الآمنة**: تسجيل حساب جديد وتسجيل الدخول بأمان
- **البحث والتصفية**: البحث عن المنتجات وتصفيتها حسب الفئة والسعر
- **سلة التسوق**: إضافة المنتجات وإدارة السلة
- **الدفع الآمن**: دعم طرق دفع متعددة (الدفع عند الاستلام، المحافظ الرقمية، البطاقات)
- **تتبع الطلبات**: متابعة حالة الطلبات في الوقت الفعلي
- **التقييمات والمراجعات**: تقييم المنتجات والتجار
- **الإشعارات**: تلقي إشعارات عن المنتجات الجديدة والخصومات

### 🏪 ميزات التجار
- **إدارة المتجر**: إنشاء وإدارة حساب المتجر
- **إدارة المنتجات**: إضافة وتعديل وحذف المنتجات مع الصور والأوصاف
- **إدارة المخزون**: تتبع كميات المنتجات
- **معالجة الطلبات**: استقبال وتأكيد ومعالجة الطلبات
- **الخصومات والعروض**: إنشاء عروض ترويجية وخصومات
- **التقارير والإحصائيات**: عرض تقارير المبيعات والإيرادات

### 👨‍💼 ميزات المسؤولين
- **إدارة المستخدمين**: مراقبة وإدارة حسابات العملاء والتجار
- **إدارة المنتجات**: التحكم في جودة المنتجات والفئات
- **إدارة الطلبات**: مراقبة جميع الطلبات والمشاكل
- **الإعدادات النظامية**: تكوين إعدادات المنصة
- **الإشعارات العامة**: إرسال إشعارات نظام واسعة

## التقنيات المستخدمة

### Backend
- **Node.js**: بيئة تشغيل JavaScript على الخادم
- **Express.js**: إطار عمل ويب خفيف الوزن وسريع
- **SQLite**: قاعدة بيانات خفيفة وموثوقة
- **bcryptjs**: تشفير آمن لكلمات المرور
- **jsonwebtoken (JWT)**: إدارة المصادقة والجلسات
- **CORS**: دعم الطلبات من نطاقات مختلفة
- **Multer**: معالجة رفع الملفات والصور

### Frontend
- **HTML5**: البنية الأساسية للصفحات
- **CSS3**: التنسيق والتصميم الحديث
- **JavaScript (ES6+)**: التفاعلية والديناميكية
- **Responsive Design**: تصميم متجاوب يعمل على جميع الأجهزة

### الأمان
- **HTTPS**: تشفير البيانات أثناء النقل
- **Password Hashing**: تشفير كلمات المرور باستخدام bcrypt
- **JWT Authentication**: مصادقة آمنة بناءً على التوكنات
- **Input Validation**: التحقق من صحة المدخلات
- **SQL Injection Prevention**: حماية من هجمات SQL

## التثبيت والتشغيل

### 1. استنساخ المستودع
```bash
git clone https://github.com/your-username/yemen-ecommerce-platform.git
cd yemen-ecommerce-platform
```

### 2. تثبيت المتطلبات
```bash
npm install
```

### 3. إعداد متغيرات البيئة
انسخ ملف `.env.example` إلى `.env` وعدّل القيم:
```bash
cp .env.example .env
```

ثم عدّل الملف:
```env
PORT=5000
NODE_ENV=development
JWT_SECRET=your_secret_key_here
```

### 4. تشغيل الخادم
```bash
npm start
```

أو للتطوير مع إعادة تشغيل تلقائية:
```bash
npm run dev
```

### 5. فتح التطبيق
افتح المتصفح وانتقل إلى:
```
http://localhost:5000
```

## مثال على الاستخدام

### تسجيل عميل جديد
```bash
curl -X POST http://localhost:5000/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{
    "firstName": "أحمد",
    "lastName": "محمد",
    "email": "ahmed@example.com",
    "phone": "+967771234567",
    "password": "SecurePass123!"
  }'
```

### تسجيل الدخول
```bash
curl -X POST http://localhost:5000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "email": "ahmed@example.com",
    "password": "SecurePass123!"
  }'
```

### الحصول على قائمة المنتجات
```bash
curl http://localhost:5000/api/products
```

### إنشاء طلب جديد
```bash
curl -X POST http://localhost:5000/api/orders/create \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -d '{
    "items": [
      {"productId": 1, "quantity": 2}
    ],
    "shippingAddress": "صنعاء، شارع النيل",
    "paymentMethod": "cod"
  }'
```

## وسائل الدفع المدعومة

### 1. الدفع عند الاستلام (COD)
- الطريقة الأكثر شيوعاً في اليمن
- لا يتطلب معلومات بطاقة
- الدفع عند استلام الطلب

### 2. M-Mocha (MTN Yemen)
- محفظة رقمية من MTN Yemen
- تحويل أموال فوري
- رقم هاتف + رمز PIN

### 3. Sabafon Pay
- محفظة رقمية من Sabafon
- تحويل أموال آمن
- رقم هاتف + رمز PIN

### 4. بطاقات الائتمان/الخصم
- دعم البطاقات الدولية
- معالجة آمنة عبر بوابة دفع
- تشفير كامل للبيانات

## الخصوصية والأمان

- **تشفير البيانات**: جميع البيانات مشفرة أثناء النقل والتخزين
