# توثيق قاعدة البيانات (Database Documentation)

تستخدم منصة التجارة الإلكترونية اليمنية قاعدة بيانات SQLite، وهي قاعدة بيانات خفيفة الوزن ومناسبة للتطبيقات الصغيرة والمتوسطة، وللتطوير السريع. يمكن استبدالها بسهولة بقواعد بيانات علائقية أخرى مثل PostgreSQL أو MySQL في بيئات الإنتاج الكبيرة.

## هيكل قاعدة البيانات (Database Schema)

تتكون قاعدة البيانات من الجداول الرئيسية التالية:

### 1. جدول `users` (المستخدمون)
يخزن معلومات العملاء، البائعين، والمسؤولين.

| العمود | النوع | الوصف | ملاحظات |
| :--- | :--- | :--- | :--- |
| `id` | `INTEGER` | المعرف الفريد للمستخدم | مفتاح أساسي، زيادة تلقائية |
| `email` | `TEXT` | البريد الإلكتروني للمستخدم | فريد، مطلوب |
| `password` | `TEXT` | كلمة المرور المشفرة | مطلوب |
| `first_name` | `TEXT` | الاسم الأول للمستخدم | مطلوب |
| `last_name` | `TEXT` | الاسم الأخير للمستخدم | مطلوب |
| `phone` | `TEXT` | رقم الهاتف | مطلوب |
| `role` | `TEXT` | دور المستخدم (`customer`, `vendor`, `admin`) | القيمة الافتراضية: `customer` |
| `address` | `TEXT` | عنوان المستخدم | |
| `city` | `TEXT` | المدينة | |
| `country` | `TEXT` | الدولة | القيمة الافتراضية: `Yemen` |
| `zip_code` | `TEXT` | الرمز البريدي | |
| `profile_image` | `TEXT` | مسار صورة الملف الشخصي | |
| `is_active` | `INTEGER` | حالة تفعيل الحساب (0=غير نشط، 1=نشط) | القيمة الافتراضية: `1` |
| `created_at` | `TEXT` | تاريخ ووقت إنشاء الحساب | `YYYY-MM-DD HH:MM:SS` |
| `updated_at` | `TEXT` | تاريخ ووقت آخر تحديث للحساب | `YYYY-MM-DD HH:MM:SS` |

### 2. جدول `products` (المنتجات)
يخزن معلومات المنتجات المعروضة للبيع.

| العمود | النوع | الوصف | ملاحظات |
| :--- | :--- | :--- | :--- |
| `id` | `INTEGER` | المعرف الفريد للمنتج | مفتاح أساسي، زيادة تلقائية |
| `vendor_id` | `INTEGER` | معرف البائع الذي يملك المنتج | مفتاح خارجي لجدول `users` |
| `name` | `TEXT` | اسم المنتج | مطلوب |
| `description` | `TEXT` | وصف مفصل للمنتج | مطلوب |
| `category` | `TEXT` | فئة المنتج (مثال: `phones`, `electronics`) | مطلوب |
| `price` | `REAL` | سعر المنتج | مطلوب، > 0 |
| `currency` | `TEXT` | عملة السعر | القيمة الافتراضية: `YER` |
| `stock` | `INTEGER` | الكمية المتوفرة في المخزون | القيمة الافتراضية: `0` |
| `images` | `TEXT` | مسارات صور المنتج (JSON array) | |
| `rating` | `REAL` | متوسط تقييم المنتج | القيمة الافتراضية: `0` |
| `discount` | `REAL` | نسبة الخصم (%) | القيمة الافتراضية: `0` |
| `tags` | `TEXT` | كلمات مفتاحية للمنتج (JSON array) | |
| `is_active` | `INTEGER` | حالة تفعيل المنتج (0=غير نشط، 1=نشط) | القيمة الافتراضية: `1` |
| `created_at` | `TEXT` | تاريخ ووقت إنشاء المنتج | `YYYY-MM-DD HH:MM:SS` |
| `updated_at` | `TEXT` | تاريخ ووقت آخر تحديث للمنتج | `YYYY-MM-DD HH:MM:SS` |

### 3. جدول `orders` (الطلبات)
يخزن معلومات الطلبات التي يقوم بها العملاء.

| العمود | النوع | الوصف | ملاحظات |
| :--- | :--- | :--- | :--- |
| `id` | `INTEGER` | المعرف الفريد للطلب | مفتاح أساسي، زيادة تلقائية |
| `order_id` | `TEXT` | رقم الطلب الفريد | يتم إنشاؤه تلقائياً |
| `customer_id` | `INTEGER` | معرف العميل الذي قام بالطلب | مفتاح خارجي لجدول `users` |
| `items` | `TEXT` | تفاصيل المنتجات في الطلب (JSON array) | `[{product_id, quantity, price}]` |
| `total_amount` | `REAL` | إجمالي مبلغ الطلب (بدون الشحن) | مطلوب، > 0 |
| `currency` | `TEXT` | عملة الطلب | القيمة الافتراضية: `YER` |
| `shipping_address` | `TEXT` | عنوان الشحن | مطلوب |
| `shipping_city` | `TEXT` | مدينة الشحن | |
| `shipping_zip_code` | `TEXT` | الرمز البريدي للشحن | |
| `shipping_cost` | `REAL` | تكلفة الشحن | القيمة الافتراضية: `0` |
| `payment_method` | `TEXT` | طريقة الدفع (`cod`, `mmocha`, `sabafon`, `card`) | مطلوب |
| `payment_status` | `TEXT` | حالة الدفع (`pending`, `completed`, `failed`) | القيمة الافتراضية: `pending` |
| `order_status` | `TEXT` | حالة الطلب (`pending`, `confirmed`, `shipped`, `delivered`, `cancelled`) | القيمة الافتراضية: `pending` |
| `notes` | `TEXT` | ملاحظات إضافية على الطلب | |
| `created_at` | `TEXT` | تاريخ ووقت إنشاء الطلب | `YYYY-MM-DD HH:MM:SS` |
| `updated_at` | `TEXT` | تاريخ ووقت آخر تحديث للطلب | `YYYY-MM-DD HH:MM:SS` |

### 4. جدول `reviews` (المراجعات)
يخزن تقييمات ومراجعات العملاء للمنتجات.

| العمود | النوع | الوصف | ملاحظات |
| :--- | :--- | :--- | :--- |
| `id` | `INTEGER` | المعرف الفريد للمراجعة | مفتاح أساسي، زيادة تلقائية |
| `product_id` | `INTEGER` | معرف المنتج الذي تم تقييمه | مفتاح خارجي لجدول `products` |
| `user_id` | `INTEGER` | معرف المستخدم الذي قام بالتقييم | مفتاح خارجي لجدول `users` |
| `rating` | `INTEGER` | التقييم (من 1 إلى 5) | مطلوب، بين 1 و 5 |
| `comment` | `TEXT` | نص المراجعة | |
| `created_at` | `TEXT` | تاريخ ووقت إنشاء المراجعة | `YYYY-MM-DD HH:MM:SS` |

### 5. جدول `notifications` (الإشعارات)
يخزن الإشعارات المرسلة للمستخدمين.

| العمود | النوع | الوصف | ملاحظات |
| :--- | :--- | :--- | :--- |
| `id` | `INTEGER` | المعرف الفريد للإشعار | مفتاح أساسي، زيادة تلقائية |
| `user_id` | `INTEGER` | معرف المستخدم المستهدف | مفتاح خارجي لجدول `users` |
| `type` | `TEXT` | نوع الإشعار (مثال: `new_product`, `order_status`, `discount`) | |
| `message` | `TEXT` | نص الإشعار | مطلوب |
| `is_read` | `INTEGER` | حالة قراءة الإشعار (0=غير مقروء، 1=مقروء) | القيمة الافتراضية: `0` |
| `created_at` | `TEXT` | تاريخ ووقت إنشاء الإشعار | `YYYY-MM-DD HH:MM:SS` |

## إنشاء قاعدة البيانات (Database Initialization)

سيتم إنشاء قاعدة البيانات والجداول تلقائياً عند تشغيل الخادم لأول مرة إذا لم تكن موجودة. يمكن العثور على منطق إنشاء الجداول في ملف `src/backend/database.js` (سيتم إنشاؤه لاحقاً).

## النسخ الاحتياطي واستعادة البيانات (Backup and Restore)

يجب إجراء نسخ احتياطي منتظم لملف قاعدة البيانات (`yemen_ecommerce.db`) لضمان سلامة البيانات. يمكن استعادة البيانات عن طريق استبدال ملف قاعدة البيانات الحالي بنسخة احتياطية.

## ملاحظات الأمان

- **تشفير البيانات الحساسة**: يجب تشفير أي بيانات حساسة قبل تخزينها في قاعدة البيانات (مثل كلمات المرور). يتم ذلك باستخدام `bcrypt`.
- **منع حقن SQL**: يجب استخدام الاستعلامات المُجهزة (Prepared Statements) أو ORMs لمنع هجمات حقن SQL.
- **التحكم في الوصول**: يجب أن تكون هناك طبقة منطقية للتحكم في وصول المستخدمين إلى البيانات بناءً على أدوارهم (عميل، بائع، مسؤول).
